# Экотропа Белый Яр — интерактивная карта

Интерактивная карта маршрута экотропы «Белый Яр» с точками интереса, фотографиями и описаниями.

## 🌐 Демо
Сайт доступен по адресу: [https://EcoTrailWhiteYar.github.io/white-yar-map/](https://EcoTrailWhiteYar.github.io/white-yar-map/)

## 🛠 Технологии
- HTML5, CSS3, JavaScript
- [Leaflet](https://leafletjs.com/) — интерактивные карты
- GitHub Pages — хостинг

## 📁 Структура проекта
- `index.html` — главная страница
- `photos/` — фотографии точек маршрута
- `icons/` — иконки и логотип
