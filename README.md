## 📖 О проекте

Этот веб-сайт представляет собой интерактивную карту экологической тропы **«Белый Яр»**. Проект создан для того, чтобы сделать прогулку по тропе максимально удобной и познавательной. 

Карта адаптирована под мобильные устройства, поддерживает светлую тему и работает прямо в браузере без установки приложений.

## ✨ Основные возможности

-  **Интерактивная карта** на базе OpenStreetMap с возможностью переключения на спутник
-  **21 точка интереса** с подробными описаниями и фотографиями
-  **Удобный просмотр фото**: свайпы на телефоне и полноэкранный режим
-  **Адаптивный дизайн**: идеально работает как на смартфонах, так и на компьютерах
-  **Навигация по точкам**: кнопки «Далее» и «Назад» прямо в карточке точки
