# Экотропа Белый Яр — интерактивная карта

Интерактивная карта маршрута экотропы «Белый Яр» с точками интереса, фотографиями и описаниями. 
Проект создан для удобной навигации по тропе прямо с телефона.

## 🛠 Технологии
- HTML5, CSS3, JavaScript
- [Leaflet](https://leafletjs.com/) — библиотека для интерактивных карт
- GitHub Pages — бесплатный хостинг

## 📁 Структура проекта
- `index.html` — главная страница (вся верстка, стили и скрипты)
- `photos/` — фотографии точек маршрута
- `icons/` — иконки и логотип
- `.nojekyll` — служебный файл для корректной работы GitHub Pages
